# Supply Chain Performance Dashboard  

## Tech Stack
R, tidyverse, Shiny, ggplot2, plotly, DT

## Interactive Dashboard
[View Live Dashboard](https://jkg365.shinyapps.io/josh_grant_dashboard/) 

## Buisness Objectives
- Monitor on-time delivewry performance
- Identify vendor-level performance disparities
- Analyze cost variability across routes
- Evaluate shipment lead-time trends

## Project Overview
This project develops an interactive supply chain performance dashboard to monitor delivery efficiency, shipment variability, and cost exposure across vendors and routes. Transactional shipment data is transformed into structured KPIs that support operational performance monitoring, root-cause analysis, and logistics optimization.
